Offline, open, yours

Malinali lets you work with under-documented languages without cloud dependency — including when confidentiality matters.

  • On-device neural translation (MarianMT) {{ .Site.Params.marianModelCount }} open bilateral models covering {{ .Site.Params.marianLanguageCount }} languages — African Helsinki-NLP pairs included, plus a French ↔ Fula (Pulaar) model being fine-tuned. {{ .Site.Params.marianAfricanNoteEn }}
  • Use your own model MarianMT only. Paste a Hugging Face repo id; Malinali downloads it and translates offline. Built on the Marian ecosystem.
  • Offline speech transcription (Vosk) Local speech recognition beyond French: collect, transcribe, and annotate oral data with no connectivity.
  • Full confidentiality No user text is sent to third-party servers.
